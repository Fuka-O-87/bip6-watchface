# bip6-watchface
個人的に使用するスマートウォッチのデザイン変更。
Custom watch face for Amazfit Bip 6.

## Target

- Device: Amazfit Bip 6
- Resolution: 390 × 450 px
- Zepp OS: 5.0
- API Level: 4.2

## Development

- JavaScript
- Zeus CLI
- Zepp OS Simulator
- GIMP

## Status

In development.

Initial implementation goals:

- Custom background
- Image-based digital clock
- `HH:MM` time display
- Health / activity data
- Interactive touch menu
- Always-On Display support
